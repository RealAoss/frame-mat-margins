# Frame Mat Margins

Calculate centered mat borders from the frame opening and visible artwork.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

Frame width (cm) = 50, Frame height (cm) = 40, Artwork width (cm) = 40, Artwork height (cm) = 30. The first result is 5.
